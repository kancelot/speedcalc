QUICK GUIDE

Your portable scientific workspace.

Basics: Type an expression and press Enter. Operators are + - * / ^ (power) and ! (factorial); % between two values is modulo (50 % 7 gives 1). Division can also be written : or ÷. Use parentheses to group; a missing closing parenthesis at the end is added automatically. 0xF0F0 and 0b1010 enter hex and binary numbers. The R⇔D button switches trigonometry between degrees (D, the default) and radians (R), e.g. sin(30) gives 0.5 in degrees.

Typing aids: Typing (, [ or { adds the closing bracket; typing the closing bracket steps over it, and Backspace on an empty pair removes both. Selecting text and typing ( wraps it. With Colors: ON numbers, functions, variables and operators get different colors, the bracket next to the cursor and its partner are highlighted, brackets without a partner (for example an opening bracket that is never closed) are marked red, and unknown names are underlined in red. A missing closing bracket at the end is added automatically for the calculation and for the graphical preview. If a name is not recognised (sqtr(2)), the preview offers corrections to click ("Did you mean sqrt"); common alternative names such as tg, asin or cosine are suggested too.

Decimal point or comma: Both 1.5 and 1,5 are accepted as decimal numbers. A comma between two digits without spaces (1,5) is a decimal comma; in function calls separate arguments with a semicolon (max(1,5; 2)) or a comma followed by a space (max(1, 5)). When a decimal comma is read inside parentheses, a note appears next to the result. The decimal mark shown in results (and used when copying) is chosen in the Settings menu (the gear at the top right).

Powers and roots: 2^8 gives 256 and 5^2 squares a number; 2^-1 gives 0.5. sqrt(144) is the square root, cbrt(27) the cube root and root(3; 27) the n-th root (degree first). A fractional power works too: 8^(1/3). Note that -2^2 is -4. Constants such as pi and e are built in.

Percentages: A percent sign that is not followed by a value means percent. 12% is 0.12, 1000*12% is 120 and 1000/25% is 4000. After + or - the percentage is taken from everything to its left: 1000+12% is 1120, 1000-12% is 880 and 1+2+3+10% is 6.6. Modulo still works when a value follows: 50 % 7.

Functions: Browse all 150 upstream registrations by domain. Hover a function for its full signature. Two upstream chemistry placeholders (mass and molmass) are marked unavailable. log(base; x) matches SpeedCrunch; use log10(x) for base 10. round(pi;4) rounds to four decimal places.

Complex: 3 + 4i, cis(pi/4), real(3+4i), phase(1+i). DEG/RAD affects trigonometry, phase and polar display.

Lists and matrices: mean({1;2;3}), det({{1;2};{3;4}}), inv({{1;2};{3;4}}). Multiplication of two matrices uses matrix multiplication. Statistics accept individual numbers or collections.

Variables and functions: Create your own variable with radius = 12, then use it in later expressions, e.g. pi * radius^2. Variables are listed in the Variables tab of the side panel and saved with the session. ans always holds the last result; if you type an operator (+ - * / : ÷ ^ !) as the first character of an empty input, ans is inserted for you, e.g. typing *2 gives ans*2. To undo this, press Backspace right after: it removes ans and keeps the operator, so typing -, Backspace, 5 gives -5. (Writing (-5) or 0-5 works too.) Define your own function with double(x) = 2*x, then call double(21). A question mark starts a comment. As in the indexed upstream code, summation(start;end;value) repeats an already evaluated value; it does not bind a loop variable.

Showing the value of ans: Every history entry that uses ans remembers which number it was, and hovering the word ans in the history always shows that value in a tooltip (mouse only; touch screens have no hover). The Settings menu switch Show value of ans in history (default OFF) additionally displays it as a small grey line ans = value under the expression and marks the word ans in blue with a dotted underline. Long values are shortened with …; with T⇔G on G and standard results, an exact value is drawn as a stacked fraction or root, otherwise as text. Turning the switch on also reveals the values for older entries, because they are stored either way. The same line (ans = value) is added to Export history when the switch is on, and Save session always stores the values.

Units: 12.5 [cm], 3.3 [V] / 220 [ohm], molarity(2;4) (moles and litres). Supported SI/common units are m, mm, cm, km, in, ft, s, ms, min, h, kg, g, mg, A, K, mol, L, l, Hz, N, J, W, V, ohm, C, Pa, rad, deg. Compound units use * / ^. Results use SI base units. Constants insert their numerical values; their units are reference metadata.

Display options: The settings at the right of the button row control how things look; the highlighted letter shows the current choice and hovering a button explains it. Defaults: font size MD (expressions and results), basic fractions in results, 20 decimal places, degrees, standard results, graphical history, dot as decimal mark, / not stacked (OFF), preview off, colors on. At start-up, after loading a session and after a display setting changes, the history scrolls to the latest entry. The font size of expressions (history and graphical preview of the input) and the font size of results are set separately in Settings (SM 13, MD 15 and LG 17 px). The number list limits how many decimal places are shown (8, 20 or 50, or MAX for full precision); this changes the display only, the stored value is untouched. R⇔D switches radians and degrees. The small label next to an entry number (DEG or RAD) appears only when the result depends on the angle unit: trigonometric functions and their inverses, phase, the polar forms, or your own functions that use them. The last button, » / «, hides or shows the side panel. These settings are saved with the session.

Results, S·M·D: In S (standard) mode exact values are written the way they are on paper: fractions are stacked (1/3 + 1/6 gives 1 over 2), sqrt(18) shows as 3√2, sqrt(8)/6 as √2 over 3, and multiples of pi such as pi/3 are recognised. Negative values show the minus sign in front of the fraction, level with the fraction bar. Values with no simple exact form stay decimal. M is S with mixed numbers: an improper fraction such as 7/2 is shown as 3 1/2 (copied and exported as (3 + 1 / 2)). In D mode every result is a decimal number. Click a letter to choose that style directly, or click beside the letters to go to the next one (S → M → D). The exact form is found by checking the stored 80-digit value, so it is a recognition and not a symbolic calculation. Copying a pretty result copies its text form, e.g. 3*sqrt(2).

Expressions, T⇔G and preview: T⇔G chooses how finished entries in the history show the expression you typed: as typed (T) or redrawn in mathematical notation (G), including simple ones, so 3*4 is shown as 3 · 4. Entries that cannot be redrawn (assignments, function definitions, lists, units, text) stay as typed, and clicking an entry always inserts the original text. Whether a division written with / is drawn as a stacked fraction is set by the Settings switch Stack / as a fraction (click OFF, AUTO or ON directly): OFF (default) keeps it on one line (3/4), AUTO stacks it only when an operand is more than a number or a name, ON stacks every /. A division written with : or ÷ always stays on one line, e.g. (a+b):2/(c-d), and a fraction written with fr() is always stacked. In the typed view (T) and in Export history every expression is shown with the same spacing (ISO 80000-2 / TeX style): one space around binary operators (+ - * × · ÷ : = == and modulo %), none after a unary sign or inside brackets, none around ^ or before ! and a percent sign or between a function name and its bracket, and one space after each semicolon, so 2+3*-4 is shown as 2 + 3 * -4 and 3/4 as 3 / 4 (ISO 80000-2 treats the solidus as a binary operator). Expressions with fr(a;b) or abs(x) are also shown as readable text, e.g. abs(-3)*abs(-2)-abs(-fr(1;2)) as |-3| * |-2| - |-(1 / 2)| (fractions get extra brackets). The app checks that the text means exactly the same (spacing-only changes keep the same tokens; fr/abs text is decoded back and evaluated); otherwise it shows what you typed. Clicking the entry always inserts the original. All fraction bars and the operators between fractions (+ - · :) lie on one common line, even when one fraction has a taller numerator and the other a taller denominator, and nothing is padded under or over the shorter part. Use fr(numerator; denominator) (or over) to write a fraction explicitly: -fr(1;2) is a negative fraction, fr(-1;2) a negative numerator, fr(1;-2) a negative denominator, and the sign is drawn where you typed it. Mixed numbers are written mn(whole; numerator; denominator) (mixed number), e.g. mn(3;1;2) is 3 1/2 = 3 + 1/2 (whole numbers only, numerator smaller than denominator); a negative whole part makes the whole number negative, mn(-3;1;2) = −(3 + 1/2). The typed history and the export show it as (3 + 1 / 2). In the input field Tab jumps numerator → denominator → out of the fraction, and Ctrl+/ (⌘/) or F2 wraps the selection or the operand before the cursor into a fraction. A bare minus in front of a numerator or denominator is drawn exactly at the level of the fraction bar (-fr(2;3), or -2/3 with the / switch ON); put it in parentheses to keep it in the numerator ((-2)/3), so -fr(-2;3) (or -(-2)/3 with the / switch ON) is a minus in front of the fraction −2 over 3. A minus in front of another tall part (root, parentheses with a fraction) sits at the same level. The radical sign of a root covers exactly the height of what is under it. For nested fractions write parentheses, e.g. (a/b) / (c/d). Exponents are drawn raised and smaller, a fraction in an exponent as a small stacked fraction; deeper nesting uses a slash. The Preview: ON/OFF button below the input (or Alt+P) turns on a live preview of the same notation while you type, for expressions with a fraction, power or root; it does not change the history.

Settings, sessions and reset: The gear (Settings, top right) opens a menu with the decimal mark for results, the ans switch, the / stacking switch, Export history (a text file), Save session (history, variables, user functions, the stored ans values and settings in one file) and Load session (restores it, also on another device, and scrolls to the latest entry; browser storage alone does not travel with the HTML file). A session file from an older version still loads; settings it lacks return to their defaults. Clear history (just Clear on very small screens), next to the display buttons, removes only the history, and the small trash icon next to an entry number deletes just that entry (an Undo button is offered for a few seconds), while Reset (top right) erases everything saved and restores the defaults. Click the version number in the header to see what changed in the last ten versions.

Keyboard: Enter calculates, ↑ ↓ browse history, Tab completes functions, Escape clears the input. Click an expression to reuse it or a result to copy it (the displayed value is copied, without the leading =).

Precision and limits: Decimal calculations use 110 working digits and round stored results to at most 80 significant digits. This is finite-precision arithmetic; cancellation and ill-conditioned inputs can reduce accuracy. Special functions use additional guard digits. Matrices are limited to 100 × 100; bounded loops protect the browser. Population count of negative values uses a 256-bit representation. IEEE functions intentionally round to their named binary format. Random functions are not cryptographic. Dates use local time unless a UTC offset is supplied.

The input field and the colour layer now use identical font metrics (16 px, line height 24 px, no ligatures or kerning, no text size adjustment), both are exactly 24 px high and vertically centred, and the field is no longer reduced to 14 px on small screens (which also stops iOS from zooming in on focus). The colour layer is refreshed on scroll, focus, blur, key up, click, touch and selection change.

v2.12.3

  • UIThe Settings switch Stack / as a fraction (OFF · AUTO · ON): each state can be clicked directly; a click beside the states still goes to the next one. The Settings panel stays open after the choice, like the decimal mark and ans switches.

v2.12.2

  • UIThe result style is one three-state switch S·M·D (standard, mixed numbers, decimal) instead of S⇔D plus a separate mixed-number switch, which had a dead combination (decimal + mixed). Click a letter to choose it, or click beside the letters for the next style. M shows improper fractions such as 7/2 as 3 1/2, otherwise it is S. Saved sessions that had mixed numbers on load as M.
  • UIThe switches are regrouped: R⇔D │ T⇔G │ S·M·D │ decimal places │ side panel. The decimal places list now stands next to the result style it belongs to.

v2.12.1

  • FEATA single history entry can be deleted: small trash icon left of the entry number (top right of each entry). An Undo button appears for a few seconds. Variables, functions and ans are not touched, like with Clear history. The icon stays visible on narrow screens.
  • CHOREThe mixed number function is called mn(whole; numerator; denominator) (mixed number) instead of mm, which looked like millimetres. Rules, drawing and the text (3 + 1 / 2) are unchanged; mm(…) no longer exists.

v2.12.0

  • FEATNew function mm(whole; numerator; denominator) for mixed numbers: mm(3;1;2) is 3 1/2. Whole numbers only, numerator smaller than denominator; a negative whole part makes the whole number negative. Drawn as a whole number next to a stacked fraction; in the typed history and in the export it is shown as (3 + 1 / 2).
  • FEATNew switch on the main page (replaces the font size list): fractions in results as basic form (7/2) or as mixed numbers (3 1/2). A mixed result is written as (3 + 1 / 2) in copied text and in the export. Saved with the session.
  • UIThe font size of expressions and the font size of results are now separate settings (Settings menu). Sessions without the new value use the result size for both.
  • FIXAll binary operators in the graphical view (+ - · : ÷ %) now have the same space on both sides (0.2 em, the thin space of ISO 80000-2). Every minus sign, binary or unary, is drawn as the same line as the fraction bar, so minus signs and fraction bars always sit on one level.

v2.11.6

  • UIBrackets without a partner are now marked red in the input field: an opening bracket that is never closed (e.g. the outer ( in fr((1;2)*3;4), and also a closing bracket that has no opening one. With several unclosed brackets all of them are red; the calculation closes them from the right.
  • UIThe graphical preview and the graphical history now close missing brackets at the end exactly as the calculation does, so an expression that calculates is also drawn.

v2.11.5

  • UILarger text: SM is now what MD used to be (13 px), MD what LG used to be (15 px) and LG is new (17 px). Applies to results, expressions in the history and the graphical preview alike.
  • FIXThe multiplication dot in the graphical view had almost no space around it, e.g. between a large bracket and a root. It now has a clear space on both sides (0.25 em).

v2.11.4

  • FIXExpressions in the history (typed and graphical view) and the graphical preview of the input now use the same size as the results: 11, 13 and 15 px for SM, MD and LG. Before, the expressions were 2 to 6 px larger (preview 20 px). All drawing (fractions, roots, brackets, absolute value bars, exponents) is sized in em and scales with it; exponents keep a minimum of 9 px and fractions inside exponents 7.5 px so that SM stays readable.

v2.11.3

  • FIXA root over large brackets or absolute value bars, e.g. sqrt(abs(-3)*abs(-2)-abs(-fr(1;2))), no longer touches them: the top bar of the root keeps the same small gap as between nested roots. Roots without such content are unchanged.
